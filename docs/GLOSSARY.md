# Glossary / Ordlista

The tool's Swedish and English texts use these terms consistently. When
adding text (see `schedcheck/i18n.py`), pick from this list; add new terms
here first.

| Svenska | English | Note |
|---|---|---|
| remiss | remiss (preliminary schedule) | the schedule sent out for review |
| slutligt schema | final schedule | |
| referensschema | reference schedule | normally last year's final schedule |
| termin | term | VT (spring), HT (autumn) |
| läsperiod | period | P1–P4 |
| årskurs | programme year | |
| kull | cohort | intake year, e.g. HT2025 |
| utbildningsplan | study plan | per cohort |
| kursplan | syllabus | per course, valid from a term |
| kurstillfälle | course round | e.g. SF1674-12368 (VT27) |
| obligatorisk | mandatory | |
| villkorligt valfri | conditionally elective | |
| rekommenderad (valfri) | recommended (elective) | |
| behörighet (till masterprogram) | eligibility (for a master programme) | |
| tentamen (pl. tentamina) | exam | "ordinarie tentamen" = ordinary exam |
| omtentamen (pl. omtentor) | re-exam | |
| kontrollskrivning (KS) | partial exam (KS) | |
| delexamination | partial exam | |
| examinationsmodul | exam module | TEN1, LAB1, … |
| tentamensperiod | exam window | per period |
| omtentaperiod | re-exam window | Easter, June, August |
| undervisningsvecka | teaching week | "P3 v2" / "P3 w2" |
| tillfälle | occasion / session | occasion when compared between terms |
| helklass | whole class | |
| grupp | group | |
| krock / krockar | overlap / clash | |
| lokal | room | |
| platser | seats | |
| fynd | finding / issue | |
| fel / varning / granska / info | error / warning / review / info | severities |
| accepterad | accepted | in the accept list |
| kommentarsutkast | draft comments | |

TimeEdit's activity names (Föreläsning, Övning, Laboration, Seminarium,
Tentamen, Kontrollskrivning, …) and their abbreviations (F, Ö, L, …) are kept
in Swedish in both languages, as they appear in TimeEdit; the English report
explains them in its legend.
