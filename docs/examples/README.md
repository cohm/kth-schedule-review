- **Under review:** the preliminary (remiss) TimeEdit schedules for spring 2027,
  exported 2026-10-14 (CTFYS also by hand earlier that day; identical results).
- **Reference:** the published spring 2026 schedules.
- **Study plans:** ProgramVisualization, cohorts HT2026/HT2025/HT2024. The CTMAT
  study-plan data is marked as not yet verified there; treat its coverage
  findings with care.

These are snapshots of *preliminary* schedules: the findings describe the
remiss as sent out, not the final VT27 schedules. The source exports are not
in the repo. The outputs contain course codes, dates, activity types and the
schedulers' questions from the remiss-comment column, but no staff names.
