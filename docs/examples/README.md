# Example: CTFYS, VT27 remiss

A real run of `schedcheck`, kept as a worked example of what the tool finds.

- **Under review:** the preliminary (remiss) TimeEdit schedule for spring 2027,
  CTFYS years 1–3, exported 2026-10-14.
- **Reference:** the final spring 2026 schedule, exported the same day.
- **Study plans:** ProgramVisualization cohorts HT2026, HT2025, HT2024.

Files:

- [`CTFYS_VT27/CTFYS_VT27_review.html`](CTFYS_VT27/CTFYS_VT27_review.html) – the report
  ([view rendered](https://cohm.github.io/kth-schedule-review/docs/examples/CTFYS_VT27/CTFYS_VT27_review.html))
- [`CTFYS_VT27/CTFYS_VT27_kommentarer.md`](CTFYS_VT27/CTFYS_VT27_kommentarer.md) – draft comments (Swedish)
- [`CTFYS_VT27/issues.json`](CTFYS_VT27/issues.json) – machine-readable findings

This is a snapshot of a *preliminary* schedule: the findings describe the
remiss as sent out, not the final VT27 schedule. The source exports are not in
the repo; the outputs contain course codes, dates and activity types, the
schedulers' own questions from the remiss-comment column, but no staff names.
